# CityPass

CityPass is a full-stack event discovery and pass booking platform that allows users to explore events across different cities, book event passes, and manage their bookings. Organizers can create and manage events, while admins oversee users, organizers, events, and platform content.

## Tech Stack

- React.js
- Node.js
- Express.js
- MySQL
- REST APIs
- MVC Architecture
- JWT & bcrypt

## Key Features

- User registration and authentication
- Event discovery by city and category
- Event and pass management
- Pass booking and booking history
- Organizer event management
- Admin management and approval system
- Role-based access control

## Database

- Users
- Organizers
- Organizer Requests
- Events
- Cities
- Categories
- Passes
- Bookings

## Status

Currently under development. Backend setup, MySQL integration, MVC structure, and initial User APIs are completed.
